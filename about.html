Tentang Penelitian

Judul Penelitian

Sistem Deteksi Kecelakaan Otomatis Berbasis Smartphone Menggunakan Algoritma Decision Tree untuk Meningkatkan Keselamatan Pengguna Jalan

Latar Belakang

Kecelakaan pengguna jalan merupakan masalah serius yang mengakibatkan kerugian materil dan jiwa. Penelitian ini bertujuan untuk mengembangkan sistem yang dapat mendeteksi kecelakaan secara otomatis menggunakan sensor accelerometer pada smartphone.

Tujuan Penelitian

  • Tujuan Umum: Mengembangkan sistem deteksi kecelakaan otomatis yang dapat memberikan respons cepat dan akurat untuk meningkatkan keselamatan pengguna jalan.
  • Tujuan Khusus 1: Menganalisis pola data accelerometer untuk membedakan kondisi normal dan kondisi kecelakaan.
  • Tujuan Khusus 2: Mengimplementasikan algoritma Decision Tree untuk klasifikasi kecelakaan dengan akurasi tinggi.
  • Tujuan Khusus 3: Membangun aplikasi mobile berbasis Android yang dapat mendeteksi kecelakaan secara real-time.
  • Tujuan Khusus 4: Mengembangkan website informasi untuk visualisasi data dan analisis kecelakaan yang terjadi.

Metodologi Penelitian

  1. Pengumpulan Data: Mengumpulkan data accelerometer dari berbagai pengguna dan situasi menggunakan aplikasi mobile.
  2. Preprocessing Data: Membersihkan dan mempersiapkan data untuk training model machine learning.
  3. Feature Engineering: Mengekstrak fitur-fitur penting dari data accelerometer seperti magnitude, variance, dan peak detection.
  4. Training Model: Melatih algoritma Decision Tree menggunakan dataset yang telah disiapkan.
  5. Testing & Evaluation: Menguji model dengan test dataset dan mengukur akurasi, precision, recall, dan F1-score.
  6. Integration & Deployment: Mengintegrasikan model ke dalam aplikasi mobile dan website untuk implementasi real-time.

Bagaimana Sistem Menentukan Terjadi Kecelakaan?

Sistem mendeteksi kecelakaan berdasarkan kombinasi data Accelerometer, GPS, dan konfirmasi pengguna yang dianalisis menggunakan algoritma Decision Tree.

Pembacaan Sensor Accelerometer

Sensor accelerometer membaca percepatan pada tiga sumbu yaitu X, Y, dan Z.

Nilai ketiga sumbu tersebut digunakan untuk menghitung resultan percepatan menggunakan rumus:

ATt = √(AccX² + AccY² + AccZ²)

ATt = Resultan Accelerometer (m/s²)
Kondisi Tidak Kecelakaan

Sistem menganggap pengguna tidak mengalami kecelakaan apabila:

  • Nilai resultan accelerometer berada pada rentang normal
  • Perubahan percepatan tidak ekstrem
  • Kecepatan kendaraan stabil
  • Tidak terjadi benturan yang signifikan
Contoh Data: AccX = 0.24 | AccY = 1.57 | AccZ = 10.01
ATt = 10.14 Tidak Kecelakaan
Potensi Kecelakaan

Sistem mulai mencurigai adanya kecelakaan apabila terjadi perubahan percepatan secara tiba-tiba.

Indikator Potensi Kecelakaan:

ATt > 13 m/s² atau

ATt < 7 m/s²

Menunjukkan adanya benturan atau perubahan posisi yang ekstrem
Validasi Menggunakan GPS

Setelah accelerometer mendeteksi anomali, sistem memeriksa data GPS.

Parameter yang Diamati:

  • Kecepatan sebelum kejadian
  • Kecepatan setelah kejadian
Contoh: Sebelum: 45 km/jam
Sesudah: 0 km/jam
⚠ Penurunan drastis → Potensi kecelakaan
Analisis Menggunakan Decision Tree

Proses analisis kecelakaan menggunakan algoritma Decision Tree:

ATt < 13 m/s²
✓ Tidak Kecelakaan
ATt ≥ 13 m/s²

Stabil
✓ Tidak Kecelakaan
Turun Drastis

Konfirmasi Pengguna

Untuk mengurangi kesalahan deteksi, sistem memberikan konfirmasi kepada pengguna.


Kemungkinan kecelakaan terdeteksi.

Apakah Anda baik-baik saja?

Timer: 30 Detik

Pengguna memiliki waktu 30 detik untuk merespons
Penentuan Status Akhir

Sistem membuat keputusan berdasarkan respons pengguna:

Jika Pengguna Menekan YA

Status = Tidak Kecelakaan

Jika Tidak Ada Respons (30 Detik)

Status = Kecelakaan

Sistem akan:

  • Mengambil koordinat GPS
  • Mengirim notifikasi darurat
  • Menyimpan data ke Firebase
Kesimpulan Mekanisme Deteksi

Sistem menyatakan terjadi kecelakaan apabila memenuhi kriteria berikut:

Nilai accelerometer melewati ambang batas

Terjadi perubahan percepatan secara tiba-tiba

Kecepatan kendaraan turun drastis berdasarkan GPS

Pengguna tidak merespons selama 30 detik

Sebaliknya, sistem menyatakan tidak terjadi kecelakaan apabila nilai sensor masih dalam kondisi normal atau pengguna memberikan konfirmasi bahwa dirinya baik-baik saja.
